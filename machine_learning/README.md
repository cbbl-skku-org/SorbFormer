# 🤖 SorbFormer: Machine Learning Baselines

This module contains the traditional Machine Learning (ML) baseline implementations used for benchmark comparisons against SorbFormer.

Developed by the **[Computational Biology and Bioinformatics Laboratory (CBBL)](https://balalab-skku.org/)**.

---

## 📊 Models Included

The benchmark suite includes 11 regression algorithms:
1. **Random Forest Regression** (`RF_regression.py`)
2. **XGBoost Regression** (`XGBoost_regression.py`)
3. **LightGBM Regression** (`LGBM_regression.py`)
4. **CatBoost Regression** (`CatBoost_regression.py`)
5. **Extra Trees Regression** (`ET_regression.py`)
6. **AdaBoost Regression** (`AdaBoost_regression.py`)
7. **Gradient Boosting Regression** (`GB_regression.py`)
8. **Decision Tree Regression** (`DT_regression.py`)
9. **K-Nearest Neighbors Regression** (`KNN_regression.py`)
10. **Multi-Layer Perceptron** (`MLP_regression.py`)
11. **Ridge Regression** (`Ridge_regression.py`)

---

## 🚀 Usage

To execute the full machine learning benchmark suite:

```bash
python ML_run.py
```

Preprocessed datasets and feature sets are located in the `dataset/` directory.
